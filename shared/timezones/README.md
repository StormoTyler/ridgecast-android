# US time zone boundaries

`us-timezones.json` holds simplified boundaries of every US time zone: the 50 states, Puerto Rico,
the US Virgin Islands, Guam, the Northern Mariana Islands and American Samoa. The boundaries
include territorial waters, out to about 12 nautical miles.

The Android and iOS apps use it offline to:

- find a location's time zone, for the warning that a daily forecast tracker may end before the
  next 6 AM forecast at the location
- tell whether a location is inside NWS coverage: a point in no US time zone is outside it

Both are warnings only, so the simplification (about 110 m) is accepted near zone borders.

## Generating it

Don't edit `us-timezones.json` by hand. It is generated by
[`../tools/build_timezones.py`](../tools/build_timezones.py) from pinned releases of
timezone-boundary-builder and the IANA tz database, checked against their SHA-256 sums. From the
repository root:

```
python3 -m venv .venv-tools
.venv-tools/bin/pip install -r shared/tools/requirements.txt
.venv-tools/bin/python shared/tools/build_timezones.py
```

The script checks the known places in [`../fixtures/timezones.json`](../fixtures/timezones.json) against
its output and fails if any is in the wrong zone. The apps test their lookup against the same file.
To update to a new release, change the release names and SHA-256 sums at the top of the script,
rebuild, and review the diff, which lists one zone per line.
